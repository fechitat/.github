## 🚀 Guía para Colaboradores

Si has sido invitado a colaborar en la organización:

1. **Equipo de Desarrollo**:
   - Solicita acceso al equipo [`@fechitat/developers`](https://github.com/orgs/fechitat/teams/developers) para acceder a los repositorios de trabajo con permisos de contribución.
2. **Flujo de Trabajo (Git Workflow)**:
   - Todo trabajo se realiza en ramas secundarias (`feature/nombre-de-tarea` o `fix/nombre-del-bug`).
   - Cada repositorio cuenta con su propio archivo `CONTRIBUTING.md` con las instrucciones de instalación local y comandos de verificación.
   - Las integraciones a la rama principal se gestionan mediante **Pull Requests**.
3. **Identidad Visual**:
   - Respetar los colores y lineamientos oficiales de FECHITAT (Azul `#0033A0`, Rojo `#D21034`, Blanco y Negro).
