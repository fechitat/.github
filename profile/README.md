## 🚀 Guía Rápida para Desarrolladores

Si has sido invitado a colaborar en la organización:

1. **Equipo de Desarrollo**:
   - Pide que te agreguen al equipo [`@fechitat/developers`](https://github.com/orgs/fechitat/teams/developers) para obtener permisos de escritura directos en todos los repositorios.
2. **Flujo de Trabajo (Git Workflow)**:
   - Todo trabajo se realiza en ramas secundarias (`feature/nombre-de-tarea` o `fix/nombre-del-bug`).
   - Cada repositorio cuenta con su propio archivo `CONTRIBUTING.md` con los comandos exactos de compilación y verificación.
   - Las ramas se integran a `main` (o `develop` en apps móviles) mediante **Pull Requests**.
3. **Estándares de Código**:
   - Código limpio, tipado estricto en TypeScript cuando aplique y componentes UI modulares.
   - Respetar la identidad visual federativa (Azul `#0033A0` / `#1141D2`, Rojo `#D21034`, Blanco y Negro).
